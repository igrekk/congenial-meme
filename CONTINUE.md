# Продолжение разработки

Обновлено: 20 ноября 2026 года.

## Задача

Личная программа учета рабочего времени для проектов INAL, INAC, GCVU, ECGP.
Ручной ввод даты, задачи и длительности либо таймер с паузой и автоматической записью.
Позже нужны отчеты за период в пользовательский шаблон и статистика времени/объема.

## Реализация

- Python 3.10+ и стандартная библиотека, SQLite, локальный HTTP API.
- Интерфейс HTML/CSS/JavaScript, без сборки и загрузки внешних библиотек.
- Локальное приложение слушает только 127.0.0.1.
- Код сервисов в backend/, интерфейс в static/, HTTP и запуск в server.py.
- Ручные интервалы хранят начало и окончание, рассчитывают длительность и распределяются по дням. Старый ввод только даты и длительности сохранен.
- База и резервные копии в data/; эти данные исключены из Git.
- Начальное предложение React/FastAPI заменено на вариант без внешних зависимостей для простого локального запуска. Границы сервисов сохранены.

## Текущее состояние

Реализованы задачи, архив, ручные записи, редактирование и удаление с отменой,
таймер с паузой и восстановлением, разделение через полночь Москвы,
календарь месяца с объектами и часами в ячейках, подробности по нажатию на день,
итоги дня/месяца/проектов, резервные копии с восстановлением.

Проверки: 22/22 unit-теста сервисов и HTTP прошли 20 ноября 2026 года.
В браузере с настоящим API и отдельной тестовой базой проверены ручной ввод,
сохранение после перезагрузки, изменение записи, удаление с отменой,
создание задачи, запуск/пауза/продолжение/завершение таймера,
восстановление работающего и приостановленного таймера и создание резервной копии.
Ошибок JavaScript в проверенных сценариях нет.

По пожеланию пользователя основной результат перенесен в месячный календарь.
Несколько задач одного проекта объединяются в одну краткую строку ячейки;
список задач и отдельные записи раскрываются в диалоге дня. Форма ввода скрыта
до нажатия «Внести время». Правила дат и сумм вынесены в static/calendar.js;
8 проверок календаря запускаются командой node --test tests/test_calendar.cjs.
Все 8 проверок прошли. Реальный календарь также проверен в браузере: переход
месяца и соседние даты, фильтр, три отдельные задачи при двух строках проектов
в ячейке, исправление времени и пересчет итогов, добавление из пустого дня,
таймер и его восстановление, ширина 320 px без горизонтального переполнения.

Предварительная версия готова к оценке пользователем. Печать в заданный шаблон,
расширенная статистика и учет объема еще не реализованы.

Копия исходников: https://github.com/igrekk/congenial-meme (публичный репозиторий,
выбранный пользователем). Личные записи, резервные копии и временные файлы проверки
исключены. Обычный адрес запущенного приложения: http://127.0.0.1:8765.

## Как продолжить на другом компьютере

1. Склонировать этот репозиторий или распаковать его ZIP.
2. Открыть папку в Codex и прочитать README.md, CONTINUE.md и development-plan.md.
3. Запустить Start-WorkTime.cmd на Windows с Python 3.10+ или python server.py --open-browser.
4. Выполнить python -m unittest discover -s tests -v.

Для переноса собственных записей дополнительно перенесите резервную копию базы.
Код из GitHub не содержит ваши рабочие записи. Не открывайте одну SQLite-базу одновременно с двух компьютеров через общую папку.

## Ручные интервалы: обновление 20 ноября

Добавлены три способа ручного ввода: начало/окончание, начало/длительность,
дата/длительность. UI рассчитывает результат сразу, сервер независимо проверяет
его и сохраняет полный интервал с дневными частями. При редактировании, удалении
и отмене удаления учитывается весь интервал, включая переход месяца.

Схема SQLite v2 содержит manual_groups и связь дневных time_entries с группой.
Старые базы и резервные копии v1 обновляются автоматически; перед миграцией
сохраняется резервная копия. Даты и часы в API ручных интервалов — московские
локальные ISO-значения. Таймер и старые записи без начала не получают
придуманные временные отметки.

Чистые клиентские расчеты находятся в static/intervals.js. Проверки:
python -m unittest discover -s tests -v
node --test tests/test_calendar.cjs tests/test_intervals.cjs

Календари стран: backend/holidays.py + holiday_data.json, static/holidays.js/.css. Беларусь включена по умолчанию; GE/KZ/CZ подключаются кнопкой. Снимок 2026 сверяется с официальными источниками, для неизвестных ежегодных переносов есть статус baseline. Обновление проверяет доступность/изменение документа, не выдает непроверенные даты за обновленные. Связанная форма времени работает без секунд и ручного переключения направления расчета. Проверки: 40 Python и 17 JavaScript проходят; браузерная проверка пересчета в обе стороны и цветных стран выполнена.
